Listing takes three minutes. Answering the next forty messages takes three weeks. Arina does the second part — an agent negotiates every interested buyer, in parallel, and holds a floor it will never reveal.

I'm selling → I'm buying →
the one rule

The language model reads English and writes English. It never decides a price.

Every number a buyer sees is computed from the seller's policy and a Bayesian guess at what that buyer will pay. The floor and the belief state never enter a prompt — so a reservation price that isn't in the context window can't be talked out of the agent, in any language, by any buyer.

How it works

1

List it

Drop in a name, a few notes, and a photo. Arina turns it into a structured listing and puts it in your shop.

2

Set your terms

Pick a floor, a posture — firm, balanced, or eager — and how the agent weighs its tactics. Once.

3

Let it haggle

Buyers message. The agent counters, concedes by your policy, and closes — or walks. You watch the belief state tighten.

we measured it

Put a model in the negotiating seat and it does worse. Over 32 held-out buyers, the deterministic engine kept 0.31 of the floor→list spread; gpt-4o-mini 0.21, gpt-4o 0.20 — and gpt-4o sold below the floor 19% of the time. Cheaper, faster, and it doesn't give the store away.
